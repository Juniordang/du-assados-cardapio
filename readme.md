# Du Assados 🍗

Sistema de pedidos online para a rotisserie **Du Assados**, desenvolvido com HTML, CSS e JavaScript. O projeto simula uma página responsiva de cardápio, permitindo que o usuário visualize os produtos, adicione itens ao carrinho e finalize o pedido.

## 📝 Descrição

O **Du Assados** é uma aplicação web que visa facilitar o agendamento e a organização de pedidos para uma rotisserie especializada em assados. A interface é intuitiva, com destaque para imagens dos produtos e funcionalidades de carrinho de compras.

## ⚙️ Funcionalidades

✅ Exibição do cardápio com imagens e preços  
✅ Adição de itens ao carrinho com atualização automática do total  
✅ Modal com formulário para finalizar pedido (nome e endereço)  
✅ Cálculo automático da taxa de entrega  
✅ Interface responsiva e moderna  
✅ Ícones personalizados com Phosphor Icons

## 🛠️ Tecnologias Utilizadas

- **HTML5** — Estrutura da página  
- **CSS3** — Estilização e layout responsivo  
- **JavaScript** — Lógica de adição ao carrinho, manipulação do DOM e validação de formulário  
- **Phosphor Icons** — Biblioteca de ícones para a interface  
- **Google Fonts** — Fontes Inter e Space Grotesk para uma tipografia moderna
